# Nick Mugo — Portfolio

Static personal portfolio (HTML/CSS/JS, no build step), hosted on Netlify.

- `index.html` — content
- `styles.css` — design system & layout
- `main.js` — interactions (reveal, counters, spotlight, menu, clock)
- `assets/profile.jpg` — profile photo (shown in the hero; falls back to an "NM" monogram if missing)
- `netlify.toml` — headers; the contact form uses Netlify Forms

Run locally: `npx serve .` (or `python3 -m http.server`).
